# Guitar Chord Vocabulary Builder

A tool to help guitar players increase their fluency of chords and more easily sight-read.

## Features (planned)
- Chord flashcard drill — see a chord name, play it, reveal the diagram
- Chord diagram display with finger positions
- Progress tracking by chord type (open, barre, 7th, etc.)
- Randomized or category-focused practice sessions

## Stack
- Vanilla HTML / CSS / JS (single-file or modular)
- No framework dependencies

## Project Structure
```
public/       Static assets and entry HTML
src/          Core logic (chord data, drill engine)
components/   UI components
styles/       CSS
docs/         Notes and references
```

## Development
Open `public/index.html` directly in a browser, or serve with:
```bash
npx serve public
```
